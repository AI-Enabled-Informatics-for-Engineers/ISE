## Sessions (2/week)
Session A: setup + notebooks + SQL + troubleshooting  
Session B: project milestone coaching + debugging + office-hours style support

## What to emphasize
- Decisions > models
- Clarity > complexity
- Reliability > cleverness
- Explain trade-offs

## Common issues
1) Environment trouble → default to Colab  
2) Vague decisions → require a one-sentence decision statement  
3) Over-engineering → MVP first  
4) Missing interpretation → “what action happens from this output?”
