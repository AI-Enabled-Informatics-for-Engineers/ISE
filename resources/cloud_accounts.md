# Cloud & Coding Resources

You may complete this course using **any one** of the options below. Google Colab is recommended.

## Option A (recommended): Google Colab
- https://colab.research.google.com/
- No setup required. Runs in your browser.

## Option B: GitHub Codespaces
- Use the green **Code** button in GitHub → Codespaces.

## Option C: Azure for Students
- https://azure.microsoft.com/en-us/free/students

## Option D: AWS Educate
- https://aws.amazon.com/education/awseducate/

## Kaggle (datasets + notebooks)
- https://www.kaggle.com/

## Week 1 requirement
By the end of Week 1 you must be able to:
- open a notebook in Colab
- run all cells
- submit a screenshot of successful execution in Canvas
