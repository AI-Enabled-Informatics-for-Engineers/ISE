# AI-Enabled Informatics for Engineers (ISE)
Welcome to AI-Enabled Informatics for Engineers (ISE), Spring 2026!

I’m Ron Iammartino and I’ll be your instructor this semester. This course is designed to be practical, fun, and system-focused: we’ll learn how engineers build real informatics systems that turn data into decisions — and how AI can enhance that pipeline.

TA Support
Your TA is Keyi Wang (kw653@scarletmail.rutgers.edu). Students will meet with the TA twice weekly (details posted in Syllabus). TA sessions are a key part of the course and include quick check-ins and discussion “mini-defenses” to help you build confidence and learn by doing.

Course Format (Asynchronous, GitHub-First)
This is a GitHub-first course:
- GitHub is the “single source of truth” for all materials: slides, notebooks, datasets, templates, rubrics, project milestone cut sheets, and weekly instructions.
- Canvas is used for: announcements, submissions, grades, and discussions.

Think of it like this:
GitHub = learning + doing
Canvas = submitting + discussing + tracking

How Work is Graded (Quick Summary)
- Weekly Discussions: 1 point each
  • 0.6 = your Canvas post
  • 0.4 = your Thursday TA-session response (quick check-in)
- Assignments A1–A5: 6 points each
- Project Milestones M1–M6: 4 points each
- Project Milestone M7 (Final): 6 points

Tools You Can Use
You’ll have multiple options for running code:

- Local Python (optional)
We will also incorporate Rutgers student access to cloud tooling where appropriate:
- Azure for Students (Rutgers-supported student access)
- AWS Educate (Rutgers-supported student access)

Course Mindset
You do NOT need to be an AI expert to succeed here.
What you do need is curiosity and willingness to build.
We will focus on:
- decision-first thinking (data → information → decisions → actions)
- reliability, evaluation, and trust
- real tools (SQL, notebooks, cloud basics, retrieval/RAG concepts, security fundamentals)
- building a semester-long project step-by-step

I’m excited to work with you this semester. Start with the GitHub repo, follow the Week 1 instructions, and come to the TA sessions ready to talk through what you built and what you learned.
