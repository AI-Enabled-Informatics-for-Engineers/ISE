Apex Advanced Manufacturing (AAM) — Scenario Context

    

      System: AI platform across four domains: quality control RAG, procurement agent, process optimization (causal), workforce scheduling.

      RAG corpus: 12,000 SOPs, process specs, quality manuals — two document types (short self-contained specs; long hierarchical manuals).

      Agent tools: read_inventory, calculate_reorder_qty, draft_purchase_order, send_supplier_inquiry, submit_purchase_order, update_supplier_record, expedite_existing_po, cancel_purchase_order, delete_draft.

      Workforce: 340 production workers, 3 plants. Sliced groups: age cohorts, accommodation status.
    

  

  

    

      🔄 RAG Metrics (Week 10)
      

        Precision@K = hits / K (fraction retrieved that are relevant)

        Recall@K = hits / |relevant| (fraction of relevant docs retrieved)

        MRR = mean 1/rank of first relevant doc

        Local consistency: entailment-based NLI (requires ground-truth context)

        Global consistency: SelfCheckGPT (no ground truth needed)

        RAGAS faithfulness: fraction of claims supported by retrieved context
      

    

    

      🤖 Agent Concepts (Week 11)
      

        ReAct: Think → Act → Observe → repeat

        Gate levels: LOW=auto, MEDIUM=async flag, HIGH=synchronous block

        Audit log fields: timestamp, session_id, step, action_type, tool, parameters, risk_level, status, notes

        LLM01 Prompt injection · LLM08 Excessive Agency

        LLM04 DoS · LLM09 Overreliance
      

    

    

      🧠 Causality (Week 12)
      

        P(Y|X): conditional (observational) — includes confounders

        P(Y|do(X)): interventional — severs back-door paths

        Confounder: C→T and C→Y (spurious correlation)

        Back-door: P(Y|do(T)) = Σ P(Y|T,C=c)·P(C=c)

        DoWhy steps: Model → Identify → Estimate → Refute

        Placebo fail: ATE≠0 → unmeasured confounder likely
      

    

    

      🔒 Security (Week 13)
      

        STRIDE: S Spoofing · T Tampering · R Repudiation · I Disclosure · D Denial · E Elevation

        NIST AI RMF: Govern → Map → Measure → Manage

        Fairness: Dem. Parity · Equalized Odds · Equal Opportunity · Predictive Parity

        Key lifecycle: Pre-activation → Active → Deactivated → Compromised → Destroyed

        Envelope encryption: AES-256 data key wrapped with RSA public key

        HMAC: integrity without encryption; compare_digest prevents timing attacks
